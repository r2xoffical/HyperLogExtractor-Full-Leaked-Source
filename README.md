# 🔍 HyperLogExtractor - High-Speed Data Parser 🚀

---

**HyperLogExtractor**, büyük boyutlu metin dosyaları veya log yığınları içerisinden (logs, combos, data exports vb.) ihtiyacınız olan spesifik satırları saniyeler içinde ayıklayan, modern arayüzlü bir Windows masaüstü uygulamasıdır. C# ve .NET Framework 4.8 kullanılarak geliştirilmiştir.

---

## ✨ Özellikler

* ⚡ **Ultra Hızlı Ayıklama:** Regex tabanlı tarama motoru sayesinde binlerce satırlık dosyaları milisaniyeler içinde işler.
* 📂 **Çoklu Dosya Desteği:** Tek seferde birden fazla log dosyası yükleyebilir ve tümünü aynı anda tarayabilirsiniz.
* 🎨 **Modern Dark UI:** Bunifu UI bileşenleri ile güçlendirilmiş, karanlık mod odaklı ve kullanıcı dostu arayüz.
* 🔍 **Anahtar Kelime Filtreleme:** Sadece belirttiğiniz kelimeleri veya kalıpları içeren satırları yakalar.
* 🛠️ **Gelişmiş Form Tasarımı:** Sürüklenebilir başlık çubuğu, özel kenar yumuşatma (CreateRoundRectRgn) ve estetik buton tasarımları.
* 💾 **Otomatik Çıktı:** Ayıklanan verileri doğrudan kaydedilebilir formatta hazırlar.

---

## 🚀 Kurulum ve Kullanım

### Gereksinimler

* Windows İşletim Sistemi
* [.NET Framework 4.8 Runtime](https://dotnet.microsoft.com/en-us/download/dotnet-framework/net48)

### Çalıştırma

1. `hyperlogextractor.exe` dosyasını çalıştırın.
2. **LOAD FILE** butonuna basarak taramak istediğiniz log dosyalarını seçin.
3. Sağdaki arama kutusuna ayıklamak istediğiniz **anahtar kelimeyi** (Örn: `google.com`, `premium`, `admin` vb.) yazın.
4. **EXTRACT** butonuna basarak işlemi başlatın.
5. İşlem bittiğinde sonuçlar otomatik olarak ayrıştırılacaktır.

## ⚠️ Sorumluluk Reddi

Bu yazılım büyük veri setlerini yönetmek ve analiz etmek amacıyla geliştirilmiştir. Kullanıcıların işlediği verilerin içeriğinden ve bu aracın kullanım şeklinden tamamen kendileri sorumludur.
